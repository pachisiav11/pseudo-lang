Write pseudocode.
Press play. ←

Your textbook pseudocode does not have to stay on paper. Install this free extension and VS Code will actually run it — the same DECLARE, the same FOR loop, the same arrow.

Set it up — about 5 minutes See the code on GitHub
totals.pseudo 
// This runs. Really.
DECLARE Total : INTEGER
DECLARE Index : INTEGER

Total ← 0
FOR Index ← 1 TO 10
   Total ← Total + Index
NEXT Index

OUTPUT "The total is ", Total

What you need first

Two things. Both free. You probably already have the first one.

✓

Visual Studio Code

This guide assumes it is already installed on your computer. If it is not, get it from code.visualstudio.com first, then come back here.

↓

Node.js — version 20 or later

Go to nodejs.org and click the big LTS button. Run the installer and click Next through every screen. You will never open Node.js yourself — it just sits there and does the work behind the play button.

If VS Code is open right now, close it after installing Node.js. It only notices the new install when it starts up fresh.

Installing the extension

This extension is not in the VS Code Marketplace, so you download one file and add it by hand. It takes about a minute.

I am using
  1. 1

    Download the extension file

    Open the latest release page. Scroll to the bottom, to the part headed Assets, and click pseudo-lang-0.1.0.vsix.

    It saves to your Downloads folder like anything else. You do not need to open it.

    If your browser complains

    Some browsers warn about .vsix files because they are an unusual download. Choose Keep or Download anyway. The file comes straight from GitHub and is built automatically from source code you can read yourself.

    Open the download page
  2. 2

    Add it to VS Code

    Open VS Code, then:

    1. Press Ctrl Shift X to open the Extensions panel down the side.
    2. At the very top of that panel, click the … button.
    3. Choose Install from VSIX… from the menu.
    4. Find the file you just downloaded and open it.

    VS Code shows a small message in the corner saying it was installed. That is it.

    Prefer typing?

    If you like the terminal, go to your Downloads folder and run code --install-extension pseudo-lang-0.1.0.vsix instead.

  3. 3

    Write your first program

    Make a new file and save it as hello.pseudo. The .pseudo ending is what tells VS Code to treat it as pseudocode — nothing works until you have saved it with that name.

    Now type this in, or use the copy button:

    hello.pseudo 
    DECLARE Name : STRING

OUTPUT "What is your name? "
INPUT Name
OUTPUT "Hello, ", Name, "!"

    The words should change colour as you type them. That is how you know the extension has woken up.

    About that arrow

    Pseudocode uses ← to give a variable a value, and there is no such key on your keyboard. Just type <- — the two normal characters — and it becomes a real ← when you save. You can also press Alt - at any time.

  4. 4

    Run it

    Look at the top right corner of the editor. There is a ▷ play button. Click it.

    A terminal opens at the bottom of the window and your program starts. It asks for your name — click inside the terminal first, type your name, then press Enter.

    TERMINAL 
    What is your name? Priya
Hello, Priya!
    That is the whole setup

    Everything below is optional. You have a working pseudocode setup and you never have to come back to this page.

Things worth knowing

Four features that will save you time once your programs get longer.

F5 Watch it run line by line

Click the narrow strip just left of a line number to put a red dot there, then press F5. The program stops at that line and shows you every variable and what is in it. This is the fastest way to find out why an answer is wrong.

⚠ Mistakes get underlined

Save the file and anything wrong is underlined in red, with a message explaining what to write instead. You do not have to run the program to find a typo.

TAB Shortcuts for whole blocks

Type if or for or proc and press Tab. The whole block appears, ENDIF and all, already indented.

A↑ Keywords must be capitals

IF is a keyword. if is not, and the exam agrees. If a word stays grey when you expected it to change colour, check its capitals.

If something goes wrong

Almost every problem is one of these five.

The terminal says node is not recognised

Node.js is missing, or VS Code has not noticed it yet.

Install it from nodejs.org (the LTS button), then close VS Code completely and open it again. That second part matters more than people expect — VS Code only looks for Node.js when it starts.

Nothing changes colour when I type

Check the file name on the tab. It has to end in .pseudo. A file called hello.txt, or an unsaved Untitled-1, is just plain text as far as VS Code is concerned.

If the name is right, check your capitals. Keywords only colour in UPPER CASE, because that is what the Cambridge guide requires. A grey if is the extension telling you to write IF.

There is no play button in the corner

Same cause: VS Code does not think this is a pseudocode file. Save it with a .pseudo ending and the button appears.

You can also run it from the keyboard: press Ctrl Shift P, type Pseudocode: Run File, and press Enter.

I cannot find Install from VSIX…

It lives behind the … button at the top of the Extensions panel — not the menu bar at the top of the window, and not the gear on an individual extension.

Open the Extensions panel with Ctrl Shift X first, then look at the very top of that panel, in line with the word EXTENSIONS.

My program asks for input but typing does nothing

Click inside the terminal panel at the bottom of the window first. Until you do, your keystrokes are still going to the editor.

Still stuck? Open an issue on GitHub and say what you did and what happened.
